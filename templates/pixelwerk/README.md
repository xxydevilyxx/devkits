# PixelWerk Template

Professionelle One-Page-Website für einen digitalen Bildbearbeitungs-Service.

## Enthalten

- Leistungen für Produktfotos, Portraits, Immobilien, Freisteller, Objektentfernung und Social Media
- Vorher/Nachher-Portfolio
- klare Einstiegspreise
- Anfrageformular
- responsive Darstellung
- reines HTML und CSS, kein Build-Prozess

## Verwendung

1. `index.html` und `styles.css` zusammen verwenden.
2. In `index.html` `DEINE-EMAIL@BEISPIEL.DE` durch die echte Geschäftsadresse ersetzen.
3. Eigene Portfolio-Beispiele einsetzen.
4. Vor dem geschäftlichen Einsatz Impressum und Datenschutzerklärung ergänzen.

Die Vorlage ist statisch und kann direkt auf GitHub Pages, Vercel oder einem anderen Static Host eingesetzt werden.
